# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be direct about the work and kind about the person. Harassment, discrimination, and
personal attacks are not welcome here.

## Scope

This applies in the repository, issues, pull requests, discussions, and any space where
someone is representing the project.

## Reporting

Report a concern privately to **harish.seshadri@gmail.com**. Reports are reviewed
promptly and kept confidential. Maintainers may remove comments, close threads, or ban
participants when needed.
