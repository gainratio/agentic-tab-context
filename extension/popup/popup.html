Open this from your browser toolbar

This is the extension’s popup. Opening this HTML file directly cannot connect to your browser tabs.

  1. In Chrome or Chromium, open the website you want help with.
  2. Open the browser’s Extensions menu and select Agentic Tab Context.
  3. Click Let my assistant use this tab, then return to your assistant and ask what you want it to do.

Extension not loaded yet?

Open chrome://extensions in Chrome or Chromium. Turn on Developer mode, choose Load unpacked, and select the extension folder inside your Agentic Tab Context checkout.

For a connection problem, run atc doctor in your terminal to see its status and next steps.
